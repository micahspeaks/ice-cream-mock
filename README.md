# Creamy Ice Cream Website

A static, GitHub Pages-ready ice cream website concept.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload every file and the `assets` folder from this project.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.

The website uses plain HTML, CSS, and JavaScript—no installation or build step is required.
